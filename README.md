# My Daily Roadmap Routine - V5 Smart Pro

Private personal discipline system for one admin user.

## V5 fixes and upgrades

- Better phone/mobile responsive CSS
- AI stuck fix: model changed to gemini-2.5-flash and 25-second timeout added
- Midnight reset: new local-day document is created automatically after midnight
- Edit daily activities
- Download today report as TXT
- Download each achievement as TXT
- Download all achievements as CSV or JSON
- Smart dashboard cards
- Correct three channel niches:
  1. DiraIQ — Truth behind surroundings / teach what the world will not teach you
  2. 5 Highlight — 5-minute football highlights
  3. GeoMystery — geography and mysteries

## Upload to GitHub

Replace all files in the repository:

- index.html
- style.css
- app.js
- firebase-config.js
- firestore.rules
- README.md
- favicon.svg

## Firebase rules

Paste `firestore.rules` into Firebase Firestore Rules and publish.
