# V4 Gemini AI Logic Setup

Do this after uploading V4 to GitHub.

1. Open Firebase Console.
2. Open your project: daily-roadmap-routine.
3. In the left menu, go to AI Services.
4. Click AI Logic.
5. Click Get started.
6. Choose Gemini Developer API.
7. Finish the guided setup.

The app uses:

- Firebase Auth for login
- Firestore for routine data
- Firebase AI Logic for Gemini AI advice

No Gemini API key is written in app.js.

If the AI buttons show an error, it usually means Firebase AI Logic is not enabled yet.
